### GET `/v1.1/fde/lancamentos/{lastRelease}`

**Resumo:** Obter os lançamentos do tipo FDE

Obter os lançamentos do tipo FDE com base no código release

**Parâmetros:**

| Nome | Em | Obrigatório | Tipo | Descrição |
|---|---|---|---|---|
| `token` | header | sim | string | token de autenticação |
| `lastRelease` | path | sim | string | Código a ser considerado a maior na pesquisa de lançamentos (Enviar 0 para a primeira consulta) |
| `documentos` | query | não | string | Código(s) de documento(s) a ser(em) considerado(s), separados por vírgula (,) |
| `status` | query | não | string | Status a ser usado como filtro dos lançamentos: PENDENTE, BAIXADO. Não informar para retornar todos os status |

**Respostas:**

- `200`  — **ResponseFdeLancamentos1_1** = object { response }
