Endpoint de negócio

GET /v1.6/unidades — autentica, pega o token e chama um endpoint de negócio real (round-trip completo, confirmado ao vivo).

Ofertas por loja

GET /v1.0/produtounidade/ofertas — ofertas de preço vigentes de uma loja (todas as lojas do cadastro, buscadas ao vivo via /v1.6/unidades).
